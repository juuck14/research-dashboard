# 최상위 학술지 기준과 원문 비교

2026-10-22. 상태: target/기준 고정 및 round2 baseline 심사 완료. 주 target JMLR,후보 TPAMI. 후속 결과에 따라 더 쉬운 target으로 바꾸지 않는다.

- [Protocol](protocol.md): 개선 결과 전에 정한 target,비교 논문,비보상형 기준.
- [게재 논문 원문 대조](source_audit.md): 최초 JMLR3편+TPAMI1편으로 기준을 고정했고, 직접 관련된 JMLR2026 원문을 추가해 총5편을 대조했다.
- [고정된 6개 gate](fixed_rubric.md): round2 baseline은 좁은 정리의 수학적 성립과 별개로 top-journal50% 미도달.
- [Positive-graph extension 원문 대조](graph_extension_audit.md): graph spectrum이라는 기존 지식과 새로운 finite-K 분류가 제공해야 할 지식을 분리했다. 개선 중간 검토이며 최종 재심은 아니다.

이 담당은 논문 채택을 예측하거나 외부 reviewer를 대신하지 않는다. 게재 원문에서 확인한 기여 형태와 실제 연구 결과를 근거로, 저자의 자기평가가 bar를 바꾸지 않도록 하는 역할이다. 개선 후 재심은 같은 기준으로 별도 기록한다.
